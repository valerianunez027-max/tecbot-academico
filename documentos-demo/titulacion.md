## 1. Propósito

Presentar un proceso ficticio de titulación con modalidades, requisitos y etapas, para que TecBot Académico practique respuestas fundamentadas. Toda la información es de demostración.

## 2. Modalidades de ejemplo

El documento de demostración define cuatro modalidades:

1. **Tesis.** Trabajo de investigación con sustento teórico y metodológico.
2. **Tesina.** Trabajo documental o de desarrollo acotado.
3. **Proyecto integrador.** Solución técnica o prototipo con memoria y presentación.
4. **Portafolio profesional.** Conjunto de evidencias de desempeño y productos.

Estas modalidades son inventadas para el ejercicio. No deben presentarse como opciones reales.

## 3. Requisitos generales

Para este ejemplo, la persona aspirante debe:

- Haber concluido el plan de estudios.
- Tener liberado el servicio social.
- Tener concluidas las residencias profesionales.
- No tener adeudos académicos o administrativos.
- Contar con la autorización del área correspondiente.
- Presentar un anteproyecto aprobado.

El documento no define plazos ni costos.

## 5. Etapas del proceso

El proceso de ejemplo tiene seis etapas:

1. **Orientación.** La persona conoce las modalidades y elige una.
2. **Anteproyecto.** Presenta tema, problema, objetivos y metodología.
3. **Autorización.** El área revisa y aprueba la modalidad y el anteproyecto.
4. **Desarrollo.** Elabora el trabajo o proyecto con seguimiento de un asesor.
5. **Revisión.** Entrega el documento y atiende observaciones.
6. **Presentación.** Expone el trabajo ante un comité y entrega la versión final.

El documento no describe fechas de cada etapa ni nombres de sinodales.
