# TecBot Académico · Landing page

Landing page estática de TecBot Académico, creada en el curso
"Creación de software con Agentes de IA" (Congreso Ciencias Revueltas 2026).

## Contenido
- `index.html`: navbar con glassmorphism, hero y 3 tarjetas de características
- `styles.css`: estilos con variables de marca en `:root`
- `app.js`: formulario de consulta a `POST /api/consulta` (estados de carga, error y fuentes)
- `assets/logo.svg`: logotipo vectorial

## Paleta
| Uso        | Color     |
|------------|-----------|
| Fondo      | `#0B1120` |
| Superficie | `#111827` |
| Acento     | `#22D3EE` → `#10B981` |
| Texto      | `#E5E7EB` |

Tipografía: Plus Jakarta Sans (Google Fonts).

## Cómo verla
Abre `index.html` con doble clic en el navegador.
